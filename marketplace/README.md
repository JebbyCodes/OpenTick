# OpenTick pack library

Ready-made **sections** and **themes** for OpenTick. Each file in [`packs/`](packs) is a pack: download it and add it in
*Settings → Sections & packs → Add a pack*, or paste its text there. Nothing in a pack can run code or see your data (see [docs/PACKS.md](../docs/PACKS.md)).

| Pack | What it is |
| --- | --- |
| [Study planner](packs/study-planner.json) | Topics with status, confidence and a review date |
| [Garden journal](packs/garden-journal.json) | Plants, where they are, how often to water |
| [Home upkeep](packs/home-maintenance.json) | Jobs around the home with when each was last done |
| [Calm themes](packs/calm-themes.json) | Three quiet themes: Forest, Dusk, Paper |

Add your own with a pull request: see [Making and sharing one](../docs/PACKS.md#making-and-sharing-one) and [The library](../docs/PACKS.md#the-library-marketplace). `npm run packs:check` runs the same checks as CI.
